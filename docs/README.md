# Bobby 1.12.2 documentation

The project has an early LiteLoader build with bounded asynchronous Anvil persistence and rendering-only terrain hooks. Cached terrain holes in the previous build were reproduced with a 288-column regression, and the section-creation, residency and neighbor logic has been corrected. See [compatibility](COMPATIBILITY.md) for current runtime results. A native settings panel, fallback worlds, complete Bobby coverage and broader compatibility remain unfinished.
